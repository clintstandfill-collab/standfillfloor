## Project Overview

A full website was designed and built for Standfill Floor Company, a three-generation family hardwood flooring business specializing in luxury residential solid hardwood installation, sanding, finishing, and custom pattern work. The client requested a modern, upscale, craftsmanship-style website targeting high-end residential homeowners.

## Brand & Design Direction

- **Colors:** Deep charcoal (`#1a1a1a`) as the primary, warm off-white cream (`#f5f0e8`) as secondary, muted bronze/gold (`#c9a55a`) used as a tasteful accent
- **Typography:** Cormorant Garamond (elegant serif for headings) + Raleway (refined sans-serif for body)
- **Tone:** Sleek, clean, luxury residential — craftsmanship heritage meets modern design
- **Logo reference:** SF monogram with wood grain texture in a framed square, "STANDFILL" serif wordmark, "FLOOR COMPANY" spaced small caps, "EST. 1947"

## SEO & AEO Optimizations Applied

### On-Page SEO
- Optimized `<title>` tag with location keywords and establishment year
- Full `<meta description>` targeting luxury hardwood flooring search intent in Tulsa
- `<meta keywords>`, `rel="canonical"`, and `robots` meta directives
- Open Graph tags for social sharing previews
- Semantic HTML throughout — proper `<main>`, `<article>`, `<blockquote>`, heading hierarchy (H1 → H2 → H3)
- `aria-label` and `aria-hidden` accessibility attributes
- Location signals reinforced naturally in body copy

### Structured Data (Schema.org JSON-LD)
- `LocalBusiness` schema including:
  - Founder: David Standfill
  - Founding date: 1947
  - Address, phone, email, area served
  - Full service catalog with four `Offer` entries
  - Aggregate rating
- `FAQPage` schema with six question/answer pairs
- `Review` schema markup on each testimonial via `itemscope` / `itemprop`

### AEO (Answer Engine Optimization)
- Dedicated FAQ section visible on-page matching the JSON-LD schema
- Questions written to match common search and AI assistant queries
- Concise, direct answers formatted for featured snippet eligibility

## Publishing & Editing Workflow Discussed

### Hosting Options Covered
- **Netlify Drop** — drag-and-drop the HTML file for an instant free live URL (recommended first step)
- **Local preview** — double-click the HTML file to open in a browser
- **Framer** — visual editor for ongoing text and photo editing without coding

### Why Framer Was Chosen
The client is tech-savvy but not a coder and wanted to be able to edit text and swap photos independently after launch. Framer was selected because it accepts HTML imports via the official "HTML to Framer" Chrome extension and provides a visual point-and-click editing experience.

### Framer Import Process (summarized)
1. Host the HTML file on Netlify Drop to get a live URL
2. Create a free Framer account at framer.com
3. Install the "HTML to Framer" Chrome extension (published by Framer B.V.)
4. Open the live Netlify site in Chrome
5. Use the extension to copy each of the 11 sections one at a time
6. Paste each section into Framer and assemble top to bottom
7. Edit text by double-clicking, add photos via the Assets panel
8. Publish via Framer's Publish button — free subdomain or custom domain
